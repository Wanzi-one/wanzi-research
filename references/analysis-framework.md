# 四维拆解方法论

拆一个账号，最终要能回答两个层面：

- **业务层面（直答四问）**：帮哪类人 / 解决什么具体问题 / 提供什么产品服务 / 内容围绕什么；
- **结构层面（四维）**：人设定位 / 人群定位 / 内容定位 / 商业定位。

四问是结论，四维是推导路径。只有结论没有路径的报告，无法复用。

---

## 一、人设定位

看三样东西：**身份标签、可信来源、表达人格**。

### 身份的三层结构

成熟账号的人设通常是三层叠加，缺一层就有一处软肋：

1. **专业层**（为什么听你的）：学历、职业、年限、证书、项目经验；
2. **同路层**（为什么信你说的）：和用户处在同一处境——同龄、同性别、同样的起点、同样踩过坑；
3. **使命层**（为什么你不像在卖货）：把商业行为包进一个更大的目标里（让某件事变简单、把某样东西带给更多人）。

### 证据从哪来

| 证据 | 位置 |
| --- | --- |
| 身份与资历 | 账号简介、认证信息、置顶内容 |
| 人格与语气 | 正文人称、称呼方式、是否有口头禅、是否自嘲 |
| 可信度来源 | 有没有可验证的作品/案例/资质，还是纯自称 |

### 判断要点

- 人设的核心竞争力常在**反差**（冷硬专业 × 温暖表达、高学历 × 接地气）。但反差必须建立在**真实身份**上，虚构身份一旦被质疑，整个信任盘崩塌；
- 简介里如果只有「热爱」「分享」这类词，没有可验证身份，说明账号还在成长早期，或者它的信任来源完全靠内容本身。

---

## 二、人群定位

不要写「年轻女性」这种无法验证的描述。要写到**处境 + 触发场景 + 当下目标**。

### 推导路径（从内容反推，用评论验证）

1. **内容反推**：他反复讲什么困惑，就是在对谁说话；
2. **标题人称反推**：用「你」的账号在解决具体问题，用「我」的账号在讲自我叙事；
3. **评论区验证**：评论里自述的处境最真实——「我今年 32 岁转行」「生完孩子 8 个月」这类句子直接就是人群画像；
4. **互动结构验证**：收藏高说明用户要拿去用（工具型需求），转发高说明用户要替自己表达（情绪型需求）。

### 判断要点

- 同一批人会有**生命周期**：备孕 → 孕期 → 月子 → 产后 → 育儿 → 更年期。能跟着走一个用户十年的账号，商业价值远高于只做一次的账号；
- 人群过宽（谁都能看）通常意味着**转化路径不清晰**；
- 注意区分「来围观的人」和「会付钱的人」——前者决定播放，后者决定收入，两者常不是同一批人。

---

## 三、内容定位

### 先分主线和支线

- **主线**：账号反复回到的那个母题（占内容量最大、爆款最多）；
- **支线**：为获取流量接入的相关话题，给主线喂新用户。

拆解时要明确「哪条是主线」，否则会把偶然爆款误当方向。

### 五个可复用的观察角度

| 角度 | 看什么 |
| --- | --- |
| 形态 | 视频/图文比例、时长偏好、是否符合用户消费场景 |
| 结构 | 开头怎么切入、中段给什么、结尾如何收（是否留收藏理由） |
| 标题 | 高频句式：惊叹体、替人体（"原来不是我一个人"）、案例体（"0 经验 X 天做到 Y"）、后台体（"被问爆了"）、纠错体（"很多人都做错了"） |
| 钩子 | 前 3 秒/前两行用什么制造停留：提问、反常识、数字、身份代入 |
| 更新节奏 | 发布频率、连续性（有连更栏目说明有内容体系） |

### 爆款结构提取

挑 3–5 条高互动内容，逐条标注：**身份前缀 → 钩子 → 内容主体 → 情绪落点 → 行动指令**。

如果多条爆款有相同骨架，那就是可复用的公式；如果各不相同，说明爆款来自选题而非结构。

### 判断要点

- **纠错类容易爆**（"XX 很多人都做错了"）因为它同时给出「风险」和「新信息」；
- **收藏率高于点赞率**的账号，内容是工具型，适合做体系化产品；
- 挂商品比例低 ≠ 不变现，可能是刻意克制以维持信任。

## 四、商业定位

先把变现路径归类，再看客单与转化入口。

### 六种常见路径

| 路径 | 特征 | 识别信号 |
| --- | --- | --- |
| 知识付费 | 卖课、卖训练营、卖陪跑 | 主页有课程入口、评论区问"怎么报名" |
| 咨询/服务 | 卖时间与专业判断 | 私信咨询、预约、按次或按时长收费 |
| 自有品牌电商 | 内容引流自有品牌 | 品牌矩阵号、产品自述、工厂/产地道具 |
| 带货分销 | 挂别人的商品 | 商品卡多、选品杂 |
| 流量变现 | 靠流量与商单 | 内容泛化、广告植入、星图标 |
| 线下引流 | 门店/同城到店 | 城市定位、地址、到店话术 |

### 客单价怎么推

诚实做法，按可靠度排序：

1. **平台商品卡**（最可靠）：能直接读到价格；
2. **评论区线索**（较可靠）：用户会主动说出价格（"两千一次""这个课多少钱"），或有人引用；
3. **内容线索**（较弱）：提到「一对一」「陪跑半年」可推断档位，但区间宽；
4. **纯推断**（最弱）：必须标 **待验证**，并写清推断依据。

**永远不要把推断的客单价写成事实。**

### 转化入口在哪

按出现顺序找：主页简介 → 店铺/橱窗 → 商品笔记 → 评论区引导 → 私信引导 → 直播间。找到入口比猜价格重要。

### 判断要点

- 「反消费」型内容（教你省钱、骂智商税）往往有**最深的商业设计**：先存信任，等用户需要产品时只认他；
- 品牌自述的销量、复购、排名话术（"全网第一""复购七成"）要注明**来源为品牌自述**，不能写成客观事实；
- 看商业健康度不只看收入，还要看**流量是否在衰减**——爆款引擎停摆是最大风险。

## 五、评论区三类信号

评论是转化真相最直接的证据源。按用途分三类，比按情绪分类更有价值。

| 类型 | 典型内容 | 用途 |
| --- | --- | --- |
| **需求信号** | 求具体方案、问在哪买、求教程 | 直接变选题，也是产品需求清单 |
| **异议信号** | 质疑、说贵、说不信、说没用 | 认清信任风险；高赞异议是最危险的 |
| **转化信号** | 已购、已报名、反馈效果、主动推荐 | 验证变现真实性；客单价线索常在此 |

**关键判读**：如果一个账号同时存在高赞质疑（"纯骗钱"）和高赞实证（"看完直接下单"），说明**转化真实存在但信任成本很高**——这是它最大的隐患，也是对手可以攻击的软肋。

## 六、证据分级与标注规则

报告中每个关键信息必须能归入以下一档：

| 级别 | 含义 | 写法 |
| --- | --- | --- |
| **平台事实** | 平台直接返回的字段 | 可直接引用，注明采集时间 |
| **原文引用** | 简介、标题、评论原话 | 用引号，注明出处 |
| **推导结论** | 由数据与原文推出的判断 | 写明依据，标「分析判断」 |
| **待验证** | 无法确证的数字或事实 | 标 **待验证**，写清推断路径 |
| **不可用** | 平台未返回或恒为 0 | 直接说明字段不可用，不猜 |

**红线**：不编造经历、数据、产品信息；不把计划写成已完成；不把品牌自述当客观事实。

## 七、报告结构规范

按这个顺序写，读者能顺着逻辑走到结论：

1. **一句话结论**：这个账号是什么、靠什么赚钱；
2. **基础数据卡**：粉丝、内容量、形态分布、互动量级、发布时间范围、采集时间；
3. **四维拆解**：人设 / 人群 / 内容 / 商业，每维先给结论再给证据；
4. **直答四问**：帮哪类人 / 解决什么问题 / 提供什么产品 / 内容围绕什么；
5. **内容公式提取**：主线支线、爆款结构、标题与钩子句式；
6. **评论区采样**：三类信号各举实例（引用原话）；
7. **可借鉴清单**：能直接迁移的动作（区分「可直接用」「需改造」「不建议」）；
8. **风险与不确定性**：流量变化、信任风险、待验证项、字段不可用项；
9. **附录**：端点、请求数、数据来源文件。

## 八、低粉高数据筛选标准

用于关键词选题场景，判断「这个内容值得我讲」。

### 效率分

```text
效率分 = (赞 + 评论×3 + 收藏×2 + 转发×5) / max(粉丝数, 1000)
```

- 加权理由：评论、收藏、转发的获取难度与意图强度高于点赞；
- **这是内部排序的经验权重，不是任何平台的官方指标**，不得写进报告当结论；
- 粉丝数未补齐时不计算效率分，只按加权互动排序，并标注「粉丝数待补」。

### 筛选后必须人工复核

- 内容是否与自身定位相关（不能只看数据高）；
- 爆的是内容还是选题（决定能不能复用）；
- 账号是否在异常涨粉或投流；
- 发布时间是否还在有效窗口内。

## 九、多账号横向对比

做对标矩阵时，用同一套维度对齐，避免各说各话：

| 维度 | 对齐方式 |
| --- | --- |
| 人设 | 三层结构是否完整，反差点是什么 |
| 人群 | 处境 + 触发场景，是否有生命周期延展 |
| 内容 | 主线是什么，爆款靠选题还是结构 |
| 商业 | 变现路径、客单档位、转化入口 |
| 可迁移度 | 相对自己账号：可直接抄 / 需改造 / 不适用 |

**对比的终点不是"谁更强"，而是"哪条动作我能下周就做"。**
